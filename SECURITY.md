# Security

For a vulnerability in this driver, use the repository's private reporting
page: https://github.com/bschaatsbergen/turborel-go/security/advisories/new.
If private reporting is unavailable, contact the maintainer privately
through their GitHub profile. Do not post credentials or exploit details
in a public issue. Server vulnerabilities follow Turborel's SECURITY.md.

Use a current Go patch release. TCP uses verified TLS and SCRAM by default.
Plaintext trust is intended for explicitly configured local development.
